# StudyLogApp

# 勉強時間記録アプリ 要件定義書

## 1. 概要

### 1.1. アプリのコンセプト
シンプルな操作で勉強時間を記録し、グラフで可視化することで学習の継続をサポートする、ミニマルな時間管理アプリ。

### 1.2. ターゲットユーザー
シンプルな機能で手軽に学習時間を記録したい学生や社会人。

---

## 2. 機能要件

### 2.1. タイマー機能
- ストップウォッチ方式で勉強時間を計測する（開始/一時停止/完了）。

### 2.2. 履歴の管理機能
- 計測や手動で追加した勉強の記録を、一覧で確認できる。
- 履歴の一覧から、特定の記録を個別に削除できる。

### 2.3. 手動追加機能
- 過去の日付に対しても、「1時間30分」のように時間を指定して、後から記録を追加できる。

### 2.4. グラフ表示機能
- 「日別」「週別」「月別」の単位で、合計勉強時間を棒グラフで表示する。

### 2.5. 目標設定機能
- 1日の目標勉強時間を設定できる。
- ホーム画面で、目標に対する現在の達成状況がわかるように表示する。

---

## 3. 画面構成

### 3.1. ホーム画面
- タイマー（ストップウォッチ）
- 本日の合計勉強時間
- 1日の目標達成状況
- 各画面へのナビゲーション

### 3.2. 履歴画面
- 過去の勉強記録のリスト表示
- 記録の手動追加機能
- 記録の個別削除機能

### 3.3. レポート画面
- 勉強時間の棒グラフ表示（日/週/月 切り替え）

### 3.4. 設定画面
- 1日の目標時間の設定

---

## 4. 非機能要件

### 4.1. データ保存
- 勉強の記録は、スマートフォン本体のローカルデータベースに保存する。
- アプリの動作にインターネット接続は不要。

### 4.2. 対応プラットフォーム
- iOS
- Android

### 4.3. 主な使用技術
- **フレームワーク:** Flutter
- **グラフ:** fl_chart
- **データベース:** sqflite
- **状態管理:** flutter_riverpod
